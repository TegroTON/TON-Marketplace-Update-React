A React frontend prototype for an **NFT marketplace on the TON blockchain**, part of the Libermall marketplace experiments.

## Overview
An early React web interface for browsing, listing and trading NFTs on TON — one of several front-end iterations (see also [TON-Marketplace-Web-React](https://github.com/TegroTON/TON-Marketplace-Web-React)).

## Tech Stack
- **Framework:** React + TypeScript
- **TON connectivity:** TON Connect
- **Styling:** Bootstrap, Slick
